Google's Batch API request supports a cachedContent reference.

{
  "key": "sermon_001",
  "request": {
    "cachedContent": "cachedContents/YOUR_CACHE_ID",
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "Translate this complete English sermon into Tamil..."
          }
        ]
      }
    ]
  }
}

The cached content is reused; you don't insert the 140 MB corpus into every request.
